# Contribution Guidelines

* Read and agree to the [Developer Certificate of Origin](DCO1.1.txt) document.
* Fork and Create a Pull Request
    * Fork the repo, create a new sample or bug fix branch from `main` and apply your changes there. Create a _Pull Request_ from your sample/bug fix branch against the dbb `main` branch.
    * For new samples, create a sub folder in a an existing category folder.
        * New category folders can be proposed if necessary.
        * Don't forget to add a new entry to the Content table in the community [README](README.md)
    * Limit each contribution to one new sample or bug fix. Don't bundle multiple sample/changes (e.g. a new sample and a fix to an existing sample) into a single _Pull Request_ - It's better to create one PR for the new sample, and a separate PR for the fix.
    * Merge requests will be squashed into the history.
* Send an email to drbruce@us.ibm.com with a link to the Pull Request and the following statement:
    ```
    DCO 1.1 signed-off-by: Random J Developer random@developer.org.
    ```
* The contribution will be reviewed by a maintainer of the repository.
